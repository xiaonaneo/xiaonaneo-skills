# QQQ/TQQQ 数据源与口径

本文件用于执行实时行情分析时路由数据源。所有链接均为英文或国际来源；若某数据暂时不可得，要报告缺口，不用中文二手网站补齐。

## 优先来源

| 用途 | 优先来源 | 口径要求 |
|---|---|---|
| QQQ 产品信息与持仓/估值 | [Invesco QQQ](https://www.invesco.com/qqq-etf/en/home.html) | 说明是基金页面披露的 weighted harmonic P/E，还是指数 P/E；不要与 forward P/E 混写 |
| Nasdaq-100 指数资料 | [Nasdaq Index Research](https://www.nasdaq.com/solutions/global-indexes) | 用于指数方法、历史资料和成分股背景；记录发布日期 |
| QQQ/TQQQ 官方产品信息 | [ProShares UltraPro QQQ](https://www.proshares.com/our-etfs/leveraged-and-inverse/tqqq) | TQQQ 的目标是单日 3×，不能据此推导长期 3× |
| VIX | [Cboe VIX](https://www.cboe.com/tradable_products/vix/) | 标注收盘还是盘中；VIX 是隐含波动率，不是金融危机计量器 |
| 利率与宏观时间序列 | [Federal Reserve FRED](https://fred.stlouisfed.org/) | 记录 series ID、观察日和发布日期；10Y 等利率不能与不同日期的收盘价静默合并 |
| 金融压力 | [Chicago Fed NFCI](https://www.chicagofed.org/research/data/nfci/current-data)、[St. Louis Fed STLFSI](https://fred.stlouisfed.org/series/STLFSI4) | 记录指数定义、频率、水平、方向和变化速度；注意周频滞后 |
| 信用利差 | [FRED ICE BofA indices](https://fred.stlouisfed.org/categories/32345) | 优先使用同一数据体系的 HY OAS 与 IG OAS；注明 series ID 和观察日 |
| 企业盈利水平与盈利预期 | [FactSet Earnings Insight](https://insight.factset.com/) 或 Nasdaq 的英文盈利资料 | 优先使用 Nasdaq-100 聚合 EPS、同比增长、forward EPS 与分析师修正；S&P 500 只能作为背景，不能替代指数证据 |

这些是路由建议，不是保证每个页面都提供当天数据。当前值、历史百分位和均线必须在实际查询后再写入结论。

## 计算口径

- 周线：把同一交易周最后一个交易日作为周收盘；QQQ 的周 MA200 和 TQQQ 的周 MA300 使用一致的周线构造。若数据供应商直接提供周线，核对其周边界和时区。历史阶段若 QQQ 不足 200 个完整交易周，允许使用 Nasdaq-100 指数周 MA200 代理，但必须标记代理序列。
- 价格：对 split/dividend 调整方式保持一致并写明。用于趋势比较时不能把 adjusted close 与未调整 close 混用。
- 数据截止：统一使用 America/New_York 时区。只纳入截止该周最后一个交易日收盘前已经发布的数据；周频指标取最新可用观测，日频指标取该周最后一个交易日的收盘或收盘前最后观测，月频估值取最近一次已经发布的 vintage，不用月末标签代替发布日期。
- 乖离：`D = QQQ / 周MA200 - 1`。与历史乖离比较时使用截至当时可得的同口径历史序列，避免未来数据偏差。D<P80 原则上持有；P80–P90 观察并准备兑现；D≥P90 表示位置明显过热，稳定且估值合理时观察或准备少量兑现；D≥P95 表示位置极端过热。P90/P95 单独出现只形成预警，至少得到估值或金融压力确认后才执行分批卖出；三因子共振时快速提高力度。没有足够样本时只报告当前百分比，不声称处于历史极端。
- 估值：买卖阈值优先使用 Nasdaq-100 forward P/E，每次写出数值、日期、来源和同口径历史百分位。`>25` 硬性不新增买入，`20–25` 允许买但赔率一般，`<20` 便宜；forward P/E N/A 时不新增买入。单月 `≥30` 只进入估值预警，继续观察，不立即卖出；连续两个可得月度 vintage 达到 `≥30` 才算持续偏贵。Trailing 或 harmonic P/E 只能补充说明，不能代替 forward P/E 触发阈值。
- 金融压力复合序列：先将信用、流动性、波动三个压力组内的指标统一为“越高越危险”的历史百分位，组内取中位数；至少两个组可用时计算 `Stress_t = median(Gcredit,t, Gliquidity,t, Gvolatility,t)`，否则记为 N/A。再按同频周序列计算 `ΔStress_t = Stress_t - Stress_t-1` 和 `Δ²Stress_t = ΔStress_t - ΔStress_t-1`。默认 `±5` 个百分位点为稳定带，`ΔStress ≥ 5` 且 `Δ²Stress ≥ 5` 才是恶化加速；该参数须在回测前冻结。
- 缺失数据：forward P/E、周线买入门槛或金融压力复合序列任一必要输入缺失时，不新增 TQQQ；总分记为 N/A，不把缺失当作低压力、不按剩余权重补算。卖出分数缺失时不执行分数驱动的加速卖出，另有组合级紧急风险规则时除外。
- 卖出成熟度：连续两个完整周同时满足买入位置门槛后登记“策略熊市”；其后 TQQQ 连续两周重新站上周 MA300，第二个周收盘作为 `T₀`。本轮周期不因以后再次跌破或站回而重置。使用交易日计时，前 500 个交易日原则上持有；第 501 个交易日起永久评估 forward P/E、乖离和金融压力，500–700 个交易日不是强制清仓窗口。

- 历史估值百分位对比：除当前 percentile 外，报告样本区间和历史 25%、50%、75%、90%、95% 分位对应的 Nasdaq-100 forward P/E。样本不足或序列定义变化时标注覆盖边界，不跨 P/E 口径补算。
- 企业盈利：分别报告 Nasdaq-100 实际盈利水平和未来盈利变化。实际层优先使用聚合 EPS、同比增速，可得时补充利润率和盈利广度；预期层使用 forward EPS 增速和上调/下调方向。记录覆盖范围、观察日和发布日期，不用 S&P 500 盈利冒充 Nasdaq-100。
- 点时数据：历史 forward P/E、EPS 和分析师修正必须保存发布日期/时间戳及当时可见的版本；不能用事后修订序列回填过去的信号。没有可验证 vintage 时，历史评分与回测结果标为 N/A 或仅作非严格研究。
- 分位数样本：D 至少需要 260 个完整周观测，forward P/E 至少需要 60 个可比月度 vintage；未达到最小样本时只报告当前值，不触发 P80/P90/P95 或历史估值分位动作。样本窗口（扩展或冻结）必须在回测前确定。

## 交叉验证纪律

- 本节优先于 P80/P90/P95、P/E 和 Stress 阈值矩阵；阈值只描述一个维度的状态，不能独立产生完整交易结论。
- 每次分别写出均线、估值、金融压力的结论与证据，再判断三者是一致、部分一致还是冲突。
- 买入的高置信度组合是位置低、估值合理或便宜、压力稳定或改善；卖出的高置信度组合是位置过热、估值偏贵、压力恶化。
- 单一指标只能触发候选或预警，不执行实际买卖；两个维度一致时考虑分批操作，三个维度一致时才积极操作或提高力度。硬约束仍可否决操作。
- 共振权重固定为均线 20%、估值 40%、金融压力 40%。如需量化，分别计算买入方向和卖出方向的 0–100 因子分，再按 20/40/40 加权；加权分只比较同一行动层级内的置信度和速度，不能覆盖交叉验证纪律。
- 若指标冲突，不选择最支持既有观点的数据，应降低行动强度并说明哪一项可能滞后或口径不可比。
- 组合级约束：TQQQ 的 30% 本金上限只是资本上限，不是最大回撤上限。执行仓位前必须用实际日路径、费用、融资/衍生品摩擦和滑点做组合压力测试；压力测试超过用户给定的组合损失预算时，降低目标仓位或标为 N/A。

## 来源纪律

不要把新闻标题、技术分析者的判断或模型生成的估值摘要当成原始数据。新闻只用于解释事件背景，交易信号必须回到价格、估值和压力指标。发现来源之间不一致时，保留差异并解释口径，不选择看起来最支持结论的数字。
