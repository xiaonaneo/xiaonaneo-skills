# TQQQ 买卖评分表

本表用于把三因子证据转换为买入分和卖出分。评分只是行动速度的辅助刻度，不是概率、预测或独立交易信号；执行输出在“交易评分”中显示分数及其行动映射。

## 一、统一规则

- 三因子权重固定为：均线/乖离 20%，估值 40%，金融压力 40%。
- 买入分越高表示越支持买入，卖出分越高表示越支持卖出。
- 买入评分前必须通过硬门槛：`QQQ / 周MA200 - 1 ≤ 5%` 且 `TQQQ < 周MA300`；Forward P/E `>25` 仍硬性禁止新增买入，不能由评分补偿。
- 卖出评分只用于已有 TQQQ 持仓的持续评估，不设置额外时间门槛。
- 单一因子只能观察或预警；两个因子才考虑分批行动；三个因子一致才提高力度。缺失数据记为 N/A，不按剩余权重补算；N/A 因此使对应总分和数值行动映射不可用，但不否定另外两个已有效的定性因子确认。评分区间使用唯一整数分，不使用“0–20”这类无法复核的自由区间。

## 二、均线/乖离因子：20%

### 买入位置分 `M_low`

先分别给 QQQ 乖离 `d = QQQ / 周MA200 - 1` 和 TQQQ 乖离 `t = TQQQ / 周MA300 - 1` 赋分，再计算 `M_low = 0.6×M_QQQ + 0.4×M_TQQQ`。买入硬门槛仍优先执行。

| QQQ 乖离 `d` | `M_QQQ` |
|---|---:|
| `d > 20%` | 10 |
| `10% < d ≤ 20%` | 30 |
| `5% < d ≤ 10%` | 50 |
| `0% < d ≤ 5%` | 70 |
| `-10% < d ≤ 0%` | 90 |
| `d ≤ -10%` | 100 |

| TQQQ 乖离 `t` | `M_TQQQ` |
|---|---:|
| `t ≥ 0%` | 0 |
| `-10% < t < 0%` | 60 |
| `-20% ≤ t ≤ -10%` | 80 |
| `t < -20%` | 100 |

不满足买入硬门槛时，`M_low` 可以作为研究记录，但 BuyScore 不得授权新增 TQQQ。

### 卖出位置分 `M_hot`

`D = QQQ / 周MA200 - 1`，历史分位至少需要 260 个完整周观测：

| 历史乖离位置 | `M_hot` |
|---|---:|
| 百分位 `<P50` | 10 |
| `P50 ≤` 百分位 `<P75` | 30 |
| `P75 ≤` 百分位 `<P90` | 55 |
| `P90 ≤` 百分位 `<P95` | 80 |
| 百分位 `≥P95` | 95 |

`D>P90` 只表示位置过热，不等于自动卖出；必须与估值或金融压力相互验证。

## 三、估值因子：40%

核心指标使用 [sources-and-metrics.md](sources-and-metrics.md) 指定的 MacroMicro Nasdaq-100 Forward P/E 月度序列；执行前记录 URL、下载时间、口径和月度观测。当前值与至少 60 个连续月度观测必须来自该同一序列；不足时估值分为 N/A，不与 FactSet、Bloomberg、trailing P/E 或其他来源拼接。

### 买入赔率分 `V_cheap`

| Forward P/E / 状态 | `V_abs` |
|---|---:|
| `P/E > 30` | 5 |
| `25 < P/E ≤ 30` | 20 |
| `20 < P/E ≤ 25` | 52 |
| `18 ≤ P/E ≤ 20` | 78 |
| `P/E < 18` | 92 |

历史百分位分 `V_pct`：`p≤P25` 为 95，`P25<p≤P50` 为 80，`P50<p≤P75` 为 60，`P75<p≤P90` 为 30，`p>P90` 为 10。最终 `V_cheap = min(V_abs, V_pct)`；百分位缺失时估值分为 N/A。以上分数不能覆盖 `Forward P/E >25` 的买入硬否决；`P/E <20` 只表示赔率明显改善。

企业盈利只作估值验证：分别记录实际 EPS/盈利增速和 forward EPS 预期修正。盈利数据缺失时，估值分记为 N/A，不用其他来源替代。

### 卖出估值分 `V_expensive`

| 估值状态 | `V_abs_expensive` |
|---|---:|
| `P/E < 20` | 10 |
| `20 ≤ P/E < 25` | 30 |
| `25 ≤ P/E < 28` | 52 |
| `28 ≤ P/E < 30` | 72 |
| 单月 `P/E ≥ 30` | 40 |
| 连续两个月 `P/E ≥ 30` | 90 |
| 连续两个月 `P/E ≥ 30` 且盈利恶化 | 100 |

历史百分位分 `V_pct_expensive`：`p≤P25` 为 10，`P25<p≤P50` 为 25，`P50<p≤P75` 为 50，`P75<p≤P90` 为 75，`p>P90` 为 95。最终 `V_expensive = max(V_abs_expensive, V_pct_expensive)`；百分位缺失时卖出估值分为 N/A。单月 `P/E ≥30` 只进入估值预警；连续两个可得月度 vintage 达到 `≥30`，才算持续偏贵。盈利增长强于价格增长时，估值分可取区间下沿。

## 四、金融压力因子：40%

金融压力必须同时看水平、方向和速度：

`Stress`、`ΔStress`、`Δ²Stress`

数据按信用、流动性、波动、宏观四个组统一为同频周序列，具体来源和计算口径见 [sources-and-metrics.md](sources-and-metrics.md)。宏观组严格包含美国 10 年期国债名义收益率、ICE DXY、CPI、PCE 和 WTI 油价的水平/加速度；企业盈利修正属于估值验证，不重复并入金融压力分。至少两个组可用且至少包含信用或流动性组，才可形成金融压力分；宏观组 N/A 仅表示该组不参与本周复合值，不使其他已满足条件的压力分失效：

`G_macro = median(10Y国债收益率分位, DXY分位, CPI分位, PCE分位, WTI油价分位)`；`Stress_t = median(G_credit, G_liquidity, G_volatility, G_macro)`

压力水平默认划分为：`Stress≤P50` 低，`P50<Stress≤P75` 中，`P75<Stress≤P90` 高，`Stress>P90` 极高。多个状态同时成立时，买入取更低的 `F_improve`，卖出取更高的 `F_worsening`；状态不清晰时取中性分并降低行动力度。

### 买入压力改善分 `F_improve`

| 金融环境（按最符合且最保守状态取值） | `F_improve` |
|---|---:|
| 压力中高且继续恶化 | 15 |
| 压力低但正在快速恶化 | 30 |
| 压力高但恶化速度减慢 | 40 |
| 压力中等且稳定 | 55 |
| 压力低且环境稳定 | 70 |
| 压力高并开始改善 | 70 |
| 压力中低且开始改善 | 80 |
| 压力明显见顶并快速改善 | 90 |
| 状态混合或证据不足 | 50 |

压力水平高但方向改善是危机修复，不应被低水平分数误判为必须停止买入；方向和速度均确认改善后，才可提高买入力度。

### 卖出压力恶化分 `F_worsening`

| 金融环境（按最符合且最保守状态取值） | `F_worsening` |
|---|---:|
| 压力低且改善 | 10 |
| 压力低且稳定 | 20 |
| 压力中等且稳定 | 30 |
| 压力开始转坏 | 40 |
| 多项指标持续恶化 | 60 |
| 信用/流动性明显收紧 | 78 |
| 系统性压力且恶化加速 | 95 |
| 状态混合或证据不足 | 50 |

单日 VIX 跳升或单个异常指标不能单独使压力因子有效。

## 五、总分与行动映射

仅在量化或回测模式计算：

`BuyScore = 0.2M_low + 0.4V_cheap + 0.4F_improve`

`SellScore = 0.2M_hot + 0.4V_expensive + 0.4F_worsening`

| 分数 | 状态 | 买入动作 | 卖出动作 |
|---:|---|---|---|
| <40 | 无优势 | 不买 | 持有/观察 |
| 40–54 | 弱信号 | 观察或试探 | 提高警戒、少量兑现 |
| 55–69 | 中等信号 | 正常分批部署 | 正常分批兑现 |
| 70–84 | 强共振 | 提高部署力度 | 积极分批减仓 |
| ≥85 | 极强共振 | 接近既定本金上限 | 高强度降低仓位 |

动作仍受因子数量、数据完整性和现有 30% 买入本金上限约束。输出只按主 skill 规定的五段式格式给出分析、分数、行动映射和结论。

若任一评分分量 N/A，BuyScore 或 SellScore 必须为 N/A，不按剩余权重补算。此限制只约束数值评分：卖出时，`D≥P90` 加有效压力恶化加速仍是两个已确认因子，应在连续两个完整周确认后进入分批减仓；不得等待估值或宏观组补齐。估值 N/A 只意味着它不能作为第三个确认因子，也不能支持提高卖出力度。

## 六、回测要求

- 在回测开始前冻结所有分数区间、权重、指标窗口和行动映射，不根据测试结果事后调整。
- 使用点时可见的价格、forward P/E、EPS 和金融压力数据；Forward P/E 只使用一个供应商。
- 同时报告各因子参考分、总分、因子确认数量、行动状态和实际执行，但不要把分数当作成功概率。
- 至少与 QQQ、TQQQ 买入持有和现金比较费用后收益、CAGR、最大回撤、恢复时间、换手率和最差滚动损失。
