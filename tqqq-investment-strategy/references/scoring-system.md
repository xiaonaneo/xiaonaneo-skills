# TQQQ 三因子评分系统

本评分系统把用户的三因子框架变成可重复的行动层级。它不是预测模型，也不能替代三因子最高原则。

## 一、评分顺序

每次以同一个数据截止日执行以下顺序：

1. 先检查硬门槛；
2. 再判断均线、估值、金融压力三个因子是否有效；
3. 再计算各因子的 0–100 分；
4. 用因子数量限制行动上限；
5. 最后用 20%/40%/40% 加权分决定同一行动层级内的速度和力度。

单因子只提高警觉，两因子开始行动，三因子共振才允许大幅行动。加权总分不能绕过硬门槛，也不能让一个因子单独产生完整交易结论。

## 二、统一评分尺度

买入分越高，表示越支持买入；卖出分越高，表示越支持卖出。每个因子都转换到 0–100：

- 0–39：不支持该方向；
- 40–59：中性或证据不足；
- 60–79：支持该方向；
- 80–100：强支持该方向。

因子分数的 60 分只是“证据偏向该方向”的参考线，不等同于因子是否满足策略条件。因子是否有效必须按下面各因子的硬条件判断；单因子仍然只能观察，两个因子才开始行动，三个因子才允许加速。这样不会把 20–25 倍、策略允许买入但赔率一般的估值误判成买入否决。

下列表格使用明确的数学边界，避免临界值重复计分；买入估值的边界为 `20 ≤ P/E ≤ 25`、`15 ≤ P/E < 20` 和 `P/E < 15`。

缺失数据记为 N/A，不填 0，也不把缺失当作低压力或便宜估值。无法计算完整评分时，最多给出已验证的部分判断，不允许加速行动。

复合因子至少需要两个相互独立的子指标可用，并且方向/速度要有两个同频观测或两个以上指标同向确认；否则该复合因子记为 N/A。不得为了凑出 100 分而按可用子指标重新归一化权重。

## 三、买入评分

### 1. 趋势位置分

买入位置使用：

QQQ 相对周 MA200 的距离 = QQQ / 周 MA200 - 1

为使评分可重复，暂用 QQQ 距离周 MA200 不超过 5% 作为“附近”的评分默认值；如果用户另行指定，用户指定值优先。

| QQQ 距离周 MA200 | 趋势位置分 |
|---:|---:|
| ≤ 0% | 100 |
| 0% < 距离 ≤ 5% | 80 |
| 5% < 距离 ≤ 10% | 60 |
| 10% < 距离 ≤ 20% | 30 |
| > 20% | 0 |

买入硬门槛仍要求 TQQQ < 周 MA300。若该条件不满足，趋势因子不算有效，且不得新增买入；即使位置分很高，也只能观察。

### 2. 估值赔率分

Forward P/E > 25 是买入否决，不参与平均或加权补偿。

基础分：

| Forward P/E | 基础赔率分 |
|---:|---:|
| > 25 | 0，否决买入 |
| 20–25（含两端） | 60 |
| 15–20（不含 20） | 80 |
| < 15 | 100 |

历史百分位分：

| Forward P/E 历史百分位 | 百分位分 |
|---:|---:|
| ≤ P25 | 100 |
| P25 < 百分位 ≤ P50 | 80 |
| P50 < 百分位 ≤ P75 | 60 |
| P75 < 百分位 ≤ P90 | 30 |
| > P90 | 0 |

企业盈利分分别给实际 EPS 趋势和 forward EPS 修正打分，再取两者平均：稳定/增长或稳定/上修为 100，混合为 50，下降或连续下修为 0。这样两项都健康时为 100，两项都恶化时为 0，方向不一致时为 50。

估值赔率分计算为：

估值分 = 70% × 基础赔率分 + 15% × 历史百分位分 + 15% × 企业盈利分

### 3. 金融压力改善分

对信用利差、资金市场/银行流动性、VIX/MOVE、NFCI/STLFSI 等指标先按各自历史分布标准化，再使用中位数，避免单一指标主导。

- 压力水平分：先取各指标当前历史百分位的稳健中位数，再按下表转换；百分位越低，买入分越高。

| 压力历史百分位 | 压力水平分 |
|---:|---:|
| ≤ P25 | 100 |
| P25 < 百分位 ≤ P50 | 80 |
| P50 < 百分位 ≤ P75 | 60 |
| P75 < 百分位 ≤ P90 | 30 |
| > P90 | 0 |

- 方向分：确认改善 100，稳定/混合 60，确认恶化 20；
- 速度分：改善且加速 100，改善但减速 80，稳定 60，恶化但减速 40，恶化且加速 20；
- 企业盈利分：按实际 EPS 趋势和 forward EPS 修正分别取 100/50/0（健康/混合/恶化），再取两者平均。

金融压力改善分计算为：

压力改善分 = 25% × 压力水平分 + 30% × 压力方向分 + 25% × 压力速度分 + 20% × 企业盈利分

压力因子有效的最低条件是压力方向不恶化，或已出现可确认的边际改善。高压力但方向改善属于危机修复，不应被低水平分数误判为必须停止买入。

### 4. 买入共振分与行动

买入共振分：

买入分 = 20% × 趋势位置分 + 40% × 估值赔率分 + 40% × 压力改善分

行动规则：

- 只有一个因子有效：观察，不买；
- 趋势位置和估值因子有效，且未触发 P/E > 25 否决：开始行动；金融压力恶化时慢买；
- 三个因子都有效，且压力稳定或改善：加速买入；
- 普通熊市可在三因子基本一致时快速投入计划仓位；
- 极端熊市先建立基础仓，再等待压力方向改善或估值进一步下降后加速；
- 权重分数只在该行动层级内调整速度，不能让两个因子直接升级为三因子行动。

## 四、卖出评分

卖出评估通常从 T₀ 后约 500 天开始；金融压力恶化的提前预警不改变单因子观察纪律。

### 1. 位置过热分

使用 QQQ 相对周 MA200 的乖离 D，并以截至当时可得的历史分布计算百分位：

| D 历史百分位 | 位置过热分 |
|---:|---:|
| < P80 | 0 |
| P80–P90 | 50 |
| P90–P95 | 75 |
| ≥ P95 | 100 |

P90 或 P95 单独出现，只能提高警觉和准备兑现，不单独执行卖出。

### 2. 估值偏贵分

- 单月 Forward P/E > 30：40 分，只是估值预警；
- 连续两个月或以上达到 `Forward P/E ≥ 30`：75 分；
- 持续高估值且企业实际盈利下降或 forward EPS 连续下修：90–100 分。

本参考把“30 附近或以上”固定定义为 `Forward P/E ≥ 30`，把连续两个月作为评分默认参数，仅用于把“持续偏贵”机械化；数据不足时只报告已观察到的持续期，不补造月份。

### 3. 金融压力恶化分

将压力指标统一为“分数越高表示越危险”：

- 压力水平分：先取各压力指标当前历史百分位的稳健中位数，再按下表转换；百分位越高，卖出分越高。

| 压力历史百分位 | 压力水平分 |
|---:|---:|
| ≤ P25 | 0 |
| P25 < 百分位 ≤ P50 | 20 |
| P50 < 百分位 ≤ P75 | 60 |
| P75 < 百分位 ≤ P90 | 80 |
| > P90 | 100 |

- 方向分：确认恶化 100，稳定/混合 60，确认改善 20；
- 速度分：恶化且加速 100，恶化但减速 80，稳定 60，改善但减速 40，改善且加速 20；
- 企业盈利恶化分：按实际 EPS 趋势和 forward EPS 修正分别取 100/50/20（恶化/混合/健康），再取两者平均。

金融压力恶化分计算为：

压力恶化分 = 25% × 压力水平分 + 30% × 压力方向分 + 25% × 压力速度分 + 20% × 企业盈利恶化分

单日 VIX 跳升或单个指标异常不能使压力因子有效，至少需要多个维度或连续同频数据确认。

### 4. 卖出共振分与行动

卖出共振分：

卖出分 = 20% × 位置过热分 + 40% × 估值偏贵分 + 40% × 压力恶化分

因子有效条件：

- 位置因子：D ≥ P90；
- 估值因子：Forward P/E 持续处于 30 附近或以上，单月 P/E > 30 不足以有效；
- 压力因子：压力已确认恶化且速度上升。

因子分数用于表示强弱，不改变以上有效条件。D≥P90 但估值和压力正常时，位置因子单独存在，只能观察或准备少量兑现。

行动规则：

- 只有一个因子有效：观察或准备少量兑现，不实际卖出；
- 两个因子有效：开始考虑分批卖出；
- 三个因子有效：加速卖出；
- D ≥ P90、估值持续偏贵、压力恶化：积极分批卖出；
- D ≥ P95、估值持续偏贵、压力恶化加速：快速、大比例降低仓位；
- 单月 P/E > 30 且 D < P90、压力稳定/改善：继续观察；
- D ≥ P90 但 P/E 合理、盈利强、压力稳定/改善：观察或少量准备兑现，不机械清仓。

### 5. 卖出评分的行动上限

建议把加权分作为同一因子层级内的细分：

- 卖出分 < 40：观察；
- 40–59：准备或少量兑现；
- 60–79：按两因子行动规则分批卖出；
- ≥ 80：只有三因子有效时才允许加速；若不足三因子，最高降级为分批卖出。

## 五、回测纪律

- 所有因子分、百分位和行动状态必须使用当时已经发布的数据，禁止未来数据回填；
- 计算历史 P/E 和 D 百分位时，使用扩展历史或预先冻结的窗口，并记录窗口；
- 2000 周期没有完整 QQQ 周 MA200 时，若不启用 Nasdaq-100 代理，严格结果为 N/A；
- TQQQ 上市前的路径只能标为合成数据；
- 回测报告同时给出因子分、因子有效数量、加权分、行动状态和实际执行；
- 没有规定每次卖出比例时，不把“考虑分批卖出”伪装成唯一收益率。
