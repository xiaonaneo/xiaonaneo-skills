# TQQQ 买卖评分表

本表用于把三因子证据转换为买入分和卖出分。评分只是行动速度的辅助刻度，不是概率、预测或独立交易信号；执行输出在“交易评分”中显示分数及其行动映射。

## 一、统一规则

- 三因子权重固定为：均线/乖离 20%，估值 40%，金融压力 40%。
- 买入分越高表示越支持买入，卖出分越高表示越支持卖出。
- 买入评分前必须通过硬门槛：`QQQ / 周MA200 - 1 ≤ 5%` 且 `TQQQ < 周MA300`；Forward P/E `>25` 仍硬性禁止新增买入，不能由评分补偿。
- 卖出评分只用于已有 TQQQ 持仓的持续评估，不设置额外时间门槛。
- 单一因子只能观察或预警；两个因子才考虑分批行动；三个因子一致才提高力度。缺失数据记为 N/A，不按剩余权重补算。

## 二、均线/乖离因子：20%

### 买入位置分 `M_low`

通过买入硬门槛后，按 QQQ 相对周 MA200 的位置和 TQQQ 相对周 MA300 的深度给参考分：

| 状态 | `M_low` 参考分 |
|---|---:|
| 明显高于长期均线 | 0–20 |
| 接近长期均线但尚未进入机会区 | 20–40 |
| QQQ 接近周 MA200、TQQQ 接近/低于周 MA300 | 50–70 |
| QQQ 低于 MA200、TQQQ 明显低于 MA300 | 70–90 |
| 极端长期超跌 | 90–100 |

不满足买入硬门槛时，`M_low` 可以作为研究记录，但 BuyScore 不得授权新增 TQQQ。

### 卖出位置分 `M_hot`

`D = QQQ / 周MA200 - 1`，历史分位至少需要 260 个完整周观测：

| 历史乖离位置 | `M_hot` 参考分 |
|---|---:|
| <P50 | 0–20 |
| P50–P75 | 20–40 |
| P75–P90 | 40–70 |
| P90–P95 | 70–90 |
| >P95 | 90–100 |

`D>P90` 只表示位置过热，不等于自动卖出；必须与估值或金融压力相互验证。

## 三、估值因子：40%

核心指标是同一可验证供应商提供的 Nasdaq-100 forward P/E；同一次分析或回测不得跨供应商拼接。

### 买入赔率分 `V_cheap`

| Forward P/E / 状态 | `V_cheap` 参考分 |
|---|---:|
| >30 | 0–10 |
| 25–30 | 10–30 |
| 20–25 | 40–65 |
| 18–20 | 70–85 |
| <18 | 85–100 |

以上分数不能覆盖 `Forward P/E >25` 的买入硬否决；`P/E <20` 只表示赔率明显改善。历史百分位与绝对 P/E 冲突时采用更保守的定性结论。

企业盈利只作估值验证：分别记录实际 EPS/盈利增速和 forward EPS 预期修正。盈利数据缺失时，估值分记为 N/A，不用其他来源替代。

### 卖出估值分 `V_expensive`

| 估值状态 | `V_expensive` 参考分 |
|---|---:|
| P/E <20 | 0–20 |
| 20–25 | 20–40 |
| 25–28 | 40–65 |
| 28–30 | 65–80 |
| >30 且持续 | 80–100 |

单月 `P/E ≥30` 只进入估值预警；连续两个可得月度 vintage 达到 `≥30`，才算持续偏贵。盈利增长强于价格增长时，估值分可取区间下沿。

## 四、金融压力因子：40%

金融压力必须同时看水平、方向和速度：

`Stress`、`ΔStress`、`Δ²Stress`

数据按信用、流动性、波动三个组统一为同频周序列，具体来源和计算口径见 [sources-and-metrics.md](sources-and-metrics.md)。企业盈利修正属于估值验证，不重复并入金融压力分。

### 买入压力改善分 `F_improve`

| 金融环境 | `F_improve` 参考分 |
|---|---:|
| 压力低但正在快速恶化 | 20–40 |
| 压力中高且继续恶化 | 0–30 |
| 压力高但恶化速度减慢 | 30–50 |
| 压力高并开始改善 | 60–80 |
| 压力明显见顶并快速改善 | 80–100 |
| 压力低且环境稳定 | 60–80 |

压力水平高但方向改善是危机修复，不应被低水平分数误判为必须停止买入；方向和速度均确认改善后，才可提高买入力度。

### 卖出压力恶化分 `F_worsening`

| 金融环境 | `F_worsening` 参考分 |
|---|---:|
| 压力低且改善 | 0–15 |
| 压力低且稳定 | 10–25 |
| 压力开始转坏 | 30–50 |
| 多项指标持续恶化 | 50–70 |
| 信用/流动性明显收紧 | 70–85 |
| 系统性压力且恶化加速 | 85–100 |

单日 VIX 跳升或单个异常指标不能单独使压力因子有效。

## 五、总分与行动映射

仅在量化或回测模式计算：

`BuyScore = 0.2M_low + 0.4V_cheap + 0.4F_improve`

`SellScore = 0.2M_hot + 0.4V_expensive + 0.4F_worsening`

| 分数 | 状态 | 买入动作 | 卖出动作 |
|---:|---|---|---|
| <40 | 无优势 | 不买 | 持有/观察 |
| 40–54 | 弱信号 | 观察或试探 | 提高警戒、少量兑现 |
| 55–69 | 中等信号 | 正常分批部署 | 正常分批兑现 |
| 70–84 | 强共振 | 提高部署力度 | 积极分批减仓 |
| ≥85 | 极强共振 | 接近既定本金上限 | 高强度降低仓位 |

动作仍受因子数量、数据完整性和现有 30% 买入本金上限约束。输出只按主 skill 规定的五段式格式给出分析、分数、行动映射和结论。

## 六、回测要求

- 在回测开始前冻结所有分数区间、权重、指标窗口和行动映射，不根据测试结果事后调整。
- 使用点时可见的价格、forward P/E、EPS 和金融压力数据；Forward P/E 只使用一个供应商。
- 同时报告各因子参考分、总分、因子确认数量、行动状态和实际执行，但不要把分数当作成功概率。
- 至少与 QQQ、TQQQ 买入持有和现金比较费用后收益、CAGR、最大回撤、恢复时间、换手率和最差滚动损失。
