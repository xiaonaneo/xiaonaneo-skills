# TQQQ 三因子评分系统

本评分系统把用户的三因子框架变成可重复的行动层级。它不是预测模型，也不能替代三因子最高原则。

## 一、评分顺序

每次以同一个数据截止日执行以下顺序：

1. 先检查硬门槛；
2. 再判断均线、估值、金融压力三个因子是否有效；
3. 再计算各因子的 0–100 分；
4. 用因子数量限制行动上限；
5. 最后用 20%/40%/40% 加权分决定同一行动层级内的速度和力度。

单因子只提高警觉，两因子开始行动，三因子共振才允许大幅行动。加权总分不能绕过硬门槛，也不能让一个因子单独产生完整交易结论。

## 二、统一评分尺度

买入分越高，表示越支持买入；卖出分越高，表示越支持卖出。每个因子都转换到 0–100：

- 0–39：不支持该方向；
- 40–59：中性或证据不足；
- 60–79：支持该方向；
- 80–100：强支持该方向。

因子分数的 60 分只是“证据偏向该方向”的参考线，不等同于因子是否满足策略条件。因子是否有效必须按下面各因子的硬条件判断；单因子仍然只能观察，两个因子才开始行动，三个因子才允许加速。这样不会把 20–25 倍、策略允许买入但赔率一般的估值误判成买入否决。

下列表格使用明确的数学边界，避免临界值重复计分；买入估值的边界为 `20 ≤ P/E ≤ 25`、`15 ≤ P/E < 20` 和 `P/E < 15`。

缺失数据记为 N/A，不填 0，也不把缺失当作低压力或便宜估值。无法计算完整评分时，最多给出已验证的部分判断，不允许加速行动。

复合因子至少需要两个相互独立的子指标可用，并且方向/速度要有两个同频观测或两个以上指标同向确认；否则该复合因子记为 N/A。不得为了凑出 100 分而按可用子指标重新归一化权重。

### 数据就绪与因子有效性

- 买入采用 fail-closed：QQQ 周 MA200、TQQQ 周 MA300、Nasdaq-100 forward P/E、forward P/E 历史百分位或金融压力复合序列任一必要输入为 N/A 时，不新增 TQQQ；买入总分记为 N/A，不用剩余权重补算。
- 卖出评分需要卖出评估期、QQQ 乖离百分位、同口径估值月度 vintage 和金融压力复合序列同时可用；任一缺失时不执行分数驱动的卖出，也不允许加速。单独的组合级紧急风险规则不受此条限制。
- 买入趋势因子有效：完整周线数据存在，`QQQ / 周MA200 - 1 ≤ 5%`，且 `TQQQ < 周MA300`。买入估值因子有效：forward P/E 与同口径历史百分位均可得，且 `P/E ≤ 25`；盈利数据用于评分，缺失时该评分记为 N/A。买入压力因子有效：至少两个独立压力组可得，且压力方向不是确认恶化。
- 卖出位置因子有效：处于卖出评估期且 `D ≥ P90`；估值因子有效：连续两个可得的月度 vintage 均达到 `Forward P/E ≥ 30`；压力因子有效：压力复合序列确认恶化且加速。
- 因子“有效”与分数达到 60 分是两件事；先判断有效性和数据就绪，再按因子数量限制行动，最后才使用加权分。

## 三、买入评分

### 1. 趋势位置分

买入位置使用：

QQQ 相对周 MA200 的距离 = QQQ / 周 MA200 - 1

为使评分可重复，暂用 `QQQ / 周MA200 - 1 ≤ 5%` 作为买入“附近”的硬门槛；如果用户另行指定，用户指定值优先，但必须在整段回测中保持不变。

| QQQ 距离周 MA200 | 趋势位置分 |
|---:|---:|
| ≤ 0% | 100 |
| 0% < 距离 ≤ 5% | 80 |
| 5% < 距离 ≤ 10% | 60 |
| 10% < 距离 ≤ 20% | 30 |
| > 20% | 0 |

买入硬门槛仍要求 TQQQ < 周 MA300。若该条件不满足，趋势因子不算有效，且不得新增买入；即使位置分很高，也只能观察。

### 2. 估值赔率分

Forward P/E > 25 是买入否决，不参与平均或加权补偿。

基础分：

| Forward P/E | 基础赔率分 |
|---:|---:|
| > 25 | 0，否决买入 |
| 20–25（含两端） | 60 |
| 15–20（不含 20） | 80 |
| < 15 | 100 |

历史百分位分：

| Forward P/E 历史百分位 | 百分位分 |
|---:|---:|
| ≤ P25 | 100 |
| P25 < 百分位 ≤ P50 | 80 |
| P50 < 百分位 ≤ P75 | 60 |
| P75 < 百分位 ≤ P90 | 30 |
| > P90 | 0 |

企业盈利分分别给实际 EPS 趋势和 forward EPS 修正打分，再取两者平均：稳定/增长或稳定/上修为 100，混合为 50，下降或连续下修为 0。这样两项都健康时为 100，两项都恶化时为 0，方向不一致时为 50。

估值赔率分计算为：

估值分 = 70% × 基础赔率分 + 15% × 历史百分位分 + 15% × 企业盈利分

### 3. 金融压力改善分

先把指标按压力方向统一为“数值越高越危险”，再按同一完整周截止日计算三个压力组：信用组（HY OAS、IG OAS 等）、流动性组（NFCI、STLFSI 或同类资金市场指标）和波动组（VIX、MOVE 等）。

每个指标转换为截至当时的历史百分位 `qᵢ,t ∈ [0,100]`，组内取中位数 `Gg,t`，再取至少两个可用压力组的中位数：

`Stress_t = median(Gcredit,t, Gliquidity,t, Gvolatility,t)`

只允许使用在该周收盘前已经发布的数据；每日指标聚合到该周最后一个交易日，周频指标使用其最新已发布观测。若不足两个压力组，`Stress_t = N/A`。

统一定义：

`ΔStress_t = Stress_t - Stress_t-1`；`Δ²Stress_t = ΔStress_t - ΔStress_t-1`

默认以 5 个百分位点作为中性带：`ΔStress ≤ -5` 为改善，`-5 < ΔStress < 5` 为稳定，`ΔStress ≥ 5` 为恶化；恶化且 `Δ²Stress ≥ 5` 才叫恶化加速，改善且 `Δ²Stress ≤ -5` 才叫改善加速。5 个百分点是待回测的冻结参数，不得在看到结果后调整。

- 压力水平分：将 `Stress_t` 视为“越高越危险”的复合百分位，再按下表转换；百分位越低，买入分越高。

| 压力历史百分位 | 压力水平分 |
|---:|---:|
| ≤ P25 | 100 |
| P25 < 百分位 ≤ P50 | 80 |
| P50 < 百分位 ≤ P75 | 60 |
| P75 < 百分位 ≤ P90 | 30 |
| > P90 | 0 |

- 方向分：确认改善 100，稳定/混合 60，确认恶化 20；
- 速度分：改善且加速 100，改善但减速 80，稳定 60，恶化但减速 40，恶化且加速 20；

金融压力改善分计算为：

压力改善分 = 40% × 压力水平分 + 35% × 压力方向分 + 25% × 压力速度分

压力因子有效的最低条件是 `Stress_t` 可得、至少两个压力组可得，且压力方向不是确认恶化。高压力但方向改善属于危机修复，不应被低水平分数误判为必须停止买入；但只有方向和速度都按上述同频规则确认后，才允许加速。

### 4. 买入共振分与行动

买入共振分：

买入分 = 20% × 趋势位置分 + 40% × 估值赔率分 + 40% × 压力改善分

行动规则：

- 只有一个因子有效：观察，不买；
- 趋势位置和估值因子有效，且未触发 P/E > 25 否决：开始行动；金融压力恶化时慢买；
- 三个因子都有效，且压力稳定或改善：加速买入；
- 普通熊市可在三因子基本一致时快速投入计划仓位；
- 极端熊市先建立基础仓，再等待压力方向改善或估值进一步下降后加速；
- 权重分数只在该行动层级内调整速度，不能让两个因子直接升级为三因子行动。

## 四、卖出评分

卖出评分只在周期状态进入 `SELL_EVAL` 后计算。状态依次为 `WAIT/ACCUMULATE`、`PROFIT_HOLD`、`SELL_EVAL` 和 `CLOSED`。策略熊市登记条件为连续两个完整周同时满足 `QQQ / 周MA200 - 1 ≤ 5%` 与 `TQQQ < 周MA300`；登记后，TQQQ 连续两个完整周收盘站上周 MA300，第二个周收盘日为 `T₀`。从 `T₀` 起计算美国交易日，第 501 个交易日进入 `SELL_EVAL`。此前金融压力恶化的提前预警不改变单因子观察纪律，只有组合级紧急风险规则可以越过时间门槛。

### 1. 位置过热分

使用 QQQ 相对周 MA200 的乖离 D，并以截至当时可得的历史分布计算百分位：

| D 历史百分位 | 位置过热分 |
|---:|---:|
| < P80 | 0 |
| P80 ≤ 百分位 < P90 | 50 |
| P90 ≤ 百分位 < P95 | 75 |
| ≥ P95 | 100 |

P90 或 P95 单独出现，只能提高警觉和准备兑现，不单独执行卖出。

### 2. 估值偏贵分

- 单月 Forward P/E ≥ 30：40 分，只是估值预警；
- 连续两个月或以上达到 `Forward P/E ≥ 30`：75 分；
- 持续高估值且仅有实际盈利下降或 forward EPS 连续下修之一：90 分；两者同时成立：100 分。

本参考把“30 附近或以上”固定定义为 `Forward P/E ≥ 30`，把连续两个月作为评分默认参数，仅用于把“持续偏贵”机械化；数据不足时只报告已观察到的持续期，不补造月份。

### 3. 金融压力恶化分

将压力指标统一为“分数越高表示越危险”：

- 压力水平分：将 `Stress_t` 视为“越高越危险”的复合百分位，再按下表转换；百分位越高，卖出分越高。

| 压力历史百分位 | 压力水平分 |
|---:|---:|
| ≤ P25 | 0 |
| P25 < 百分位 ≤ P50 | 20 |
| P50 < 百分位 ≤ P75 | 60 |
| P75 < 百分位 ≤ P90 | 80 |
| > P90 | 100 |

- 方向分：确认恶化 100，稳定/混合 60，确认改善 20；
- 速度分：恶化且加速 100，恶化但减速 80，稳定 60，改善但减速 40，改善且加速 20；

金融压力恶化分计算为：

压力恶化分 = 40% × 压力水平分 + 35% × 压力方向分 + 25% × 压力速度分

单日 VIX 跳升或单个指标异常不能使压力因子有效，至少需要多个维度或连续同频数据确认。

### 4. 卖出共振分与行动

卖出共振分：

卖出分 = 20% × 位置过热分 + 40% × 估值偏贵分 + 40% × 压力恶化分

因子有效条件（仅限 `SELL_EVAL`）：

- 位置因子：D ≥ P90；
- 估值因子：连续两个可得月度 vintage 的 Forward P/E 均达到 `≥30`；单月 `P/E ≥30` 不足以有效；
- 压力因子：压力已确认恶化且速度上升。

因子分数用于表示强弱，不改变以上有效条件。D≥P90 但估值和压力正常时，位置因子单独存在，只能观察或准备少量兑现。

行动规则：

- 只有一个因子有效：观察或准备少量兑现，不实际卖出；
- 两个因子有效：开始考虑分批卖出；
- 三个因子有效：加速卖出；
- D ≥ P90、估值持续偏贵、压力恶化：积极分批卖出；
- D ≥ P95、估值持续偏贵、压力恶化加速：快速、大比例降低仓位；
- 单月 P/E ≥ 30 且 D < P90、压力稳定/改善：继续观察；
- D ≥ P90 但 P/E 合理、盈利强、压力稳定/改善：观察或少量准备兑现，不机械清仓。

### 5. 卖出评分的行动上限

建议把加权分作为同一因子层级内的细分：

- 卖出分 < 40：观察；
- 40–59：准备或少量兑现；
- 60–79：按两因子行动规则分批卖出；
- ≥ 80：只有三因子有效时才允许加速；若不足三因子，最高降级为分批卖出。

## 五、按分数映射仓位

### 1. 统一口径

- 先定义资本上限：若总资产为 `A` 且用户未给绝对金额上限，则 `Bcap = 30% × A`；若两者均有，则 `Bcap = min(30% × A，绝对金额上限)`。若总资产缺失，不编造金额；可以报告目标百分比，但金额记为 N/A。
- 组合风险预算由用户给出为总资产比例 `R`。对每条真实历史滚动路径和合成路径，定义 `lossj,h = max(0, maxu≤h(1 - NAVj,u / NAVj,0))`，其中 `h ∈ {5,20,60}` 个交易日；`L95 = maxh percentile95({lossj,h})`。风险调整后的买入预算为 `Brisk = R × A / L95`，最终 `B = min(Bcap, Brisk)`；若 `L95 = 0` 或无法计算，`Brisk = N/A`，不把零损失样本当作无限安全。
- `R`、`L95` 或组合相关资产信息缺失时，`Brisk = N/A`；不得执行三因子 90–100 分对应的 100% × B 目标，也不得把 Bcap 当作已通过风险校准。此时最多给出低级别试探目标，并明确风险预算缺口。
- 买入表中的比例是本轮熊市建仓阶段对 `B` 的累计投入目标，只适用于新资金，不是 TQQQ 市值占总资产的永久目标，也不因上涨自动再平衡。
- 卖出基准 `V₀` 是进入永久卖出评估期（通常为 `T₀` 后第 501 个美国交易日）时的 TQQQ 持仓市值；卖出表中的比例是相对 `V₀` 的累计减仓目标，不是每次复核都重复卖出该比例。
- 每次只执行“当前累计目标 − 已执行累计比例”的差额；实际可卖数量不得超过当前持仓，目标下降时不自动买回，目标上升时也不要求一次补足全部差额。实际执行仍须使用完整数据截止日和周线确认口径。
- 表中百分比是政策映射，不是成功概率或预期收益率。正式使用前必须在点时数据上冻结所有参数（包括 5 个百分点压力带、仓位表、R 和 L95 计算方式），按时间顺序完成训练/验证/样本外测试和敏感性分析；未完成时标为“未校准”，不得宣称仓位比例已被历史证明。

### 2. 买入仓位表

下表先按买入共振分给出目标，再受因子数量和硬门槛限制：

| 买入分 | 0/1 个因子有效 | 2 个因子有效（累计上限） | 3 个因子有效（累计目标上限） |
|---:|---:|---:|---:|
| 0–39 | 0% | 0% | 0% |
| 40–59 | 0% | 10% × B | 10% × B |
| 60–69 | 0% | 25% × B | 25% × B |
| 70–79 | 0% | 40% × B | 50% × B |
| 80–89 | 0% | 50% × B | 75% × B |
| 90–100 | 0% | 50% × B | 100% × B |

执行约束：

- QQQ/周 MA200 与 TQQQ/周 MA300 的买入位置条件未同时满足，或 Forward P/E > 25，目标投入直接为 0；不得用高分因子补偿。
- 2 个因子有效时，分数只把累计新资金目标提高到表中上限，最高不超过 `50% × B`；3 个因子有效且压力稳定/改善时，才允许使用“3 个因子”列加速。
- `40–59` 只代表试探性首笔目标；若数据缺失导致因子无法有效认定，仍按 0% 处理，不按分数硬买。

### 3. 卖出仓位表

卖出分只在进入卖出评估期后使用。单因子不能实际卖出；两因子开始分批，三因子才允许使用加速列：

| 卖出分 | 0/1 个因子有效 | 2 个因子有效（累计减仓上限） | 3 个因子有效（累计减仓目标上限） |
|---:|---:|---:|---:|
| 0–39 | 0% | 0% | 0% |
| 40–59 | 0% | 10% × V₀ | 10% × V₀ |
| 60–69 | 0% | 25% × V₀ | 25% × V₀ |
| 70–79 | 0% | 40% × V₀ | 50% × V₀ |
| 80–89 | 0% | 50% × V₀ | 75% × V₀ |
| 90–100 | 0% | 60% × V₀ | 80% × V₀ |

极端风险例外：只有在 `D ≥ P95`、估值持续偏贵、金融压力恶化且加速三个条件同时满足时，卖出分 90–100 的三因子累计减仓目标才可提高至 `80%–100% × V₀`；具体比例仍须说明持仓、税务和流动性假设。`D ≥ P95` 加上仅一个其他维度确认时，最多使用两因子列，不得跳过因子数量限制。

### 4. 分数与仓位的关系

评分是同一因子层级内的仓位速度和力度刻度，不是独立交易信号：

- 评分升高只提高累计目标，不改变买入/卖出的硬条件；评分下降不自动反向交易。
- 买入表不能突破总资产 30% 或绝对金额上限；卖出表也不要求清仓，除非用户另行指定清仓规则。
- 若买卖分同时偏高，分别检查当前处于建仓阶段还是盈利持仓阶段；建仓阶段的压力恶化只降低买入速度，不把同一证据同时解释为卖出授权。

## 六、回测纪律

- 所有因子分、百分位和行动状态必须使用当时已经发布的数据，禁止未来数据回填；
- 计算历史 P/E 和 D 百分位时，使用扩展历史或预先冻结的窗口，并记录窗口；
- 2000 周期没有完整 QQQ 周 MA200 时，若不启用 Nasdaq-100 代理，严格结果为 N/A；
- TQQQ 上市前的路径只能标为合成数据；
- 回测报告同时给出因子分、因子有效数量、加权分、行动状态和实际执行；
- 没有规定每次卖出比例时，不把“考虑分批卖出”伪装成唯一收益率。
