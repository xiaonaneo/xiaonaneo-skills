# QQQ 市场分析

## 适用范围

当用户要求分析当前 QQQ 市场、纳斯达克 100 市场，或直接输入 `gg` 时使用本 skill。核心对象是 QQQ 的市场状态；只有用户明确要求时才补充 TQQQ，且不能用 TQQQ 价格替代 QQQ 的趋势判断。

本 skill 的任务是：

- 判断价格与中长期趋势的位置关系；
- 判断估值是否由真实盈利和未来盈利预期支撑；
- 判断权益市场波动是否向信用市场和金融系统传播；
- 判断变量的方向、速度和市场状态是否发生迁移。

核心信息链是：

`价格 → 盈利 → 信用 → 市场状态`

AI 输出信息支持和风险结构，人负责是否交易、买卖时点、仓位、杠杆、风险预算和最终执行。不得仅根据本 skill 输出买入、卖出、持有、具体仓位或杠杆指令。

## 数据与证据规则

当前分析必须重新获取最新可用数据，不能把历史回答中的数值当作当前值。优先使用英文、国际和一手来源，例如 Nasdaq、Federal Reserve/FRED、Chicago Fed、CBOE、官方指数资料及高质量机构数据。对会变化的市场数据，注明来源、数据截至时间、频率和实时/盘中/最新收盘口径。

遵守以下不变量：

1. 趋势固定使用 QQQ 日线 `Price`、`WMA50`、`WMA200`。必须是 WMA，不能用 SMA 代替；无法取得 WMA 时明确标记数据缺失，不伪造等价结果。
2. 同时报告价格相对两条均线的乖离：`Price / WMA - 1`。
3. 斜率使用最近 20 个交易日：`WMA(t) / WMA(t-20) - 1`，并解释其扩大、收敛、走平或转向。
4. 估值优先使用 Nasdaq-100 的 Forward PE/NTM PE。不要把 Trailing PE、Forward PE 和不同数据商口径直接混合比较；冲突明显时披露口径差异，不制造虚假精度。
5. 风险链固定为 `VIX → HY OAS → NFCI`。三者频率和发布时间可能不同，必须分别注明数据日期，不能机械投票。
6. 每个核心变量尽量按 `Level × Direction × Velocity` 分析：当前水平、变化方向、变化速度。
7. 不同时间尺度不能混为同一时点结论。实时/日频价格与 VIX、可能延迟的 HY OAS、周频 NFCI 要区分。
8. 数据不可得、延迟、口径不一致或计算样本不足时，标记不确定性并缩小结论，不用推测填空。

## 分析流程

### 1. 趋势模块

观察：

- `Price vs WMA50`、`Price vs WMA200`、`WMA50 vs WMA200`；
- `Price/WMA50` 和 `Price/WMA200` 乖离率；
- WMA50、WMA200 最近 20 个交易日斜率；
- 价格是否跌破或重新站回关键均线，均线本身是否仍上升。

用事实描述状态，不把短暂跌破直接定义为长期反转，也不要把最终结论简化成“看多”或“看空”。可使用这些状态词：强趋势上升、长期上升/中期转弱、高位震荡、长期趋势受到冲击、长期趋势恶化、底部震荡、趋势修复、极端正乖离、极端负乖离。

### 2. 估值与盈利模块

至少检查：

- Nasdaq-100 Forward/NTM PE、5 年和 10 年历史百分位；
- EPS YoY 增长及其加速/减速；
- 净利润率、营业利润率及变化原因；
- 盈利广度、EPS 增长超过 10%/20% 的公司比例，以及 mega-cap 集中度；
- 未来 12 个月 Forward EPS 是创新高、横盘还是下行；
- 最近 1 个月和 3 个月的 EPS Revision Breadth：`(上调公司数 - 下调公司数) / 总公司数`。

将结果分别归类为：

- 估值：低 / 中性 / 偏高 / 极高；
- 盈利：强扩张 / 扩张 / 放缓 / 收缩；
- 盈利修正：上修 / 稳定 / 下修 / 加速下修；
- 盈利广度：强 / 中性 / 弱。

盈利 Beat Rate 只能辅助使用，因为 beat 可能来自预期先被下调。特别警惕“价格下跌 + Forward PE 下降 + Forward EPS 同时快速下降”：这可能是盈利恶化，不等于估值已经改善。

### 3. 金融风险模块

分别报告：

- `VIX`：权益市场风险偏好和短期恐慌；
- `HY OAS`：高收益债信用风险溢价、扩大/收窄方向和速度；
- `NFCI`：整体金融条件相对 0 的位置、方向和速度。

重点判断风险是否传播：

- VIX 上升、HY OAS 稳定、NFCI 稳定：更接近普通权益市场调整；
- VIX 上升、HY OAS 上升、NFCI 尚稳定：风险开始向信用市场扩散；
- VIX、HY OAS、NFCI 同时快速恶化：系统性金融压力；
- VIX 下降、HY OAS 开始收窄、NFCI 收紧速度放缓或转降：金融压力修复。

单日 VIX 暴涨不等于系统性风险，必须检查持续性和信用确认。

### 4. 状态机与状态迁移

综合判断时不要用“趋势差 + 估值便宜 + 金融风险高”的多数投票。三模块处于不同周期阶段，需说明因果链和时间顺序。

尝试将当前市场归入一个主状态：

- **扩张**：趋势向上、盈利增长、预期稳定或上修、金融压力低；
- **过热**：趋势强、正乖离大、估值高、盈利仍强、金融风险尚低；
- **趋势恶化**：价格/均线结构破坏、WMA50 转弱、WMA200 尚未明显恶化；
- **盈利衰退**：Forward EPS 下调、修正广度转负、盈利广度下降且下修加快；
- **金融压力**：VIX 高位、HY OAS 快速扩大、NFCI 快速收紧；
- **修复**：金融压力停止恶化，信用和波动改善，盈利下修放缓，价格与均线开始修复。

同时报告状态变化：稳定、轻微恶化、加速恶化、改善或加速改善。关注边际变化，不要求价格、盈利和金融风险同时触底。

必要时与 2000 科技泡沫、2008 全球金融危机、2020 COVID 流动性冲击、2022 加息与估值压缩熊市比较。历史比较要对照估值、盈利、盈利修正、信用利差、金融条件、均线结构和风险传播速度，并明确当前与案例的不同，不做机械类比。

Fed 政策、实际利率、美债收益率、收益率曲线、CPI/PCE、就业、GDP、ISM、美元、流动性、财政政策、AI/CapEx 周期、集中度和市场宽度只能作为解释变量。核心指标负责识别状态，辅助变量负责解释状态，避免用过多宏观变量事后解释行情。
